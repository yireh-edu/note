이레 노트 · 학습지 올리는 방법

[이레 노트는]
  PDF를 바탕에 깔고 그 위에 펜·형광펜으로 쓰고 그리는 앱입니다.
  - 학생: 선생님 학습지를 열어 풀고 [선생님께 보내기] → 필기가 들어간 PDF가 카톡으로 갑니다.
  - 선생님: 내 PDF(교재·학습지)를 열어 수업 화면에 띄우고 판서하거나, 학생이 보낸 PDF를 열어 빨간 펜으로 채점합니다.
  - 휴대폰·태블릿에서 [PDF 열기]로 연 파일은 그 기기 안에만 있고 인터넷에 올라가지 않습니다.

[폴더 구성]
  sheets.js      ← 학습지 목록. 이 파일과 sheets 폴더만 선생님이 고칩니다.
  sheets/        ← 학습지 PDF
  index.html, assets/, icons/, manifest.webmanifest, sw.js   ← 앱 파일 (고치지 마세요)

[새 학습지를 낼 때]
  1. 학습지 PDF를 sheets 폴더에 넣습니다. (파일 이름은 영어·숫자로: 예 2026-10-07-m2.pdf)
  2. sheets.js를 메모장이나 VS Code로 열고, 목록 맨 위에 한 줄을 추가합니다.
       { id: '2026-10-07-중2', title: '중2 일차함수 학습지', file: 'sheets/2026-10-07-m2.pdf', due: '2026-10-10' },
  3. GitHub Desktop에서 Commit → Push 하면 학생 화면에 나타납니다.
  ※ 같은 학습지를 고쳐 올렸으면 v: 2 처럼 숫자를 붙이거나 올려 주세요. (학생 기기가 새 파일을 받습니다)
     이미 학생이 쓰기 시작했다면 쪽 모양이 달라지지 않게 고쳐 주세요. 필기 위치는 쪽 기준이라 내용이 밀리면 어긋납니다.

[학생 결과 받기]
  학생이 [선생님께 보내기]를 누르면 '이름-학습지제목.pdf' 파일이 만들어지고,
  휴대폰 공유 목록에서 카카오톡 → 선생님(또는 반 단톡방)을 골라 보냅니다.
  받은 PDF는 첫 화면 [학생 PDF 채점] → [학생 PDF 열기]로 엽니다. 빨간 펜으로 시작하고, 도구 막대에 ○ ✓ ✗ 도장이 생깁니다.
  (도장: 고른 뒤 채점할 곳을 톡. 크기는 [굵기]로) 다 하면 [채점 돌려주기] → 카톡으로 그 학생에게 보냅니다.
  파일 이름은 '원래이름-채점.pdf'로 만들어지고, 첫 화면 목록에 '돌려줌'이 표시됩니다.

[수업 화면]
  PDF를 연 뒤 [수업 화면]을 누르면 한 쪽씩 화면 가득 보입니다.
  아래 막대의 ◀ ▶ 또는 키보드 화살표(발표용 리모컨)로 넘기고, 펜으로 바로 판서합니다.
  손가락으로 옆으로 밀어도 넘어갑니다(확대하지 않았을 때).

[수업할 때 쓰는 도구]
  - 레이저: 펜으로 가리키면 빨간 꼬리가 잠깐 보였다 사라집니다. 필기는 남지 않습니다.
  - 가림막: 답이 있는 곳을 끌어서 상자로 가립니다. 수업 중에 톡 누르면 열리고, 다시 누르면 닫힙니다.
    다시 열면 모두 가려진 상태로 돌아오고, 보내기·저장한 PDF에는 들어가지 않습니다. 지우개로 문지르면 없어집니다.
  - 타이머: 1~30분 또는 직접 적은 시간. 화면 오른쪽 위에 보이고, 누르면 멈춤/계속, 끝나면 소리와 함께 빨갛게 깜빡입니다.
  - 빈 쪽 넣기: [더보기] → 백지·줄 노트·모눈. 지금 쪽 뒤에 들어가고, 보내기·저장한 PDF에도 들어갑니다.
    넣은 쪽에서 [더보기] → [이 넣은 쪽 빼기]로 뺍니다.

[쓰기 편하게]
  - 즐겨찾기 펜(맨 앞 1·2·3): 누르면 그 색·굵기로 바로. 지금 펜을 저장하려면 칸을 길게 누릅니다.
  - 부분 지우개: [지우개]를 한 번 더 누르면 '부분 지우개'(문지른 부분만). 다시 누르면 선 통째로.
  - 도형 맞춤: 선을 긋고 펜을 떼지 않은 채 잠깐 멈추면 반듯한 직선·원·삼각형·사각형이 됩니다.
    직선은 바뀐 뒤에도 펜을 움직여 끝점을 옮길 수 있습니다. 끄려면 [더보기] → 도형 맞춤.
  - 글자: 넣을 곳을 톡 → 적고 [넣기]. 넣은 글자를 다시 누르면 고치거나 지울 수 있습니다. 색은 지금 펜 색.
  - 올가미: 필기를 빙 둘러 그려 고른 뒤, 끌어서 옮기거나 아래 막대에서 복제·지우기.
  - 이 쪽 필기 모두 지우기는 [더보기] 안에 있습니다.

[펜과 손가락]
  - 애플펜슬·S펜을 한 번이라도 쓰면 손가락은 화면 옮기기만 합니다. 손바닥이 닿아도 써지지 않습니다.
  - 펜이 없으면 손가락 하나로 씁니다. 도구 막대의 [손가락: 쓰기/이동]으로 바꿀 수 있습니다.
  - 두 손가락: 확대·축소와 화면 옮기기
  - S펜 옆 버튼을 누른 채 쓰면 지우개가 됩니다.

[학습지 마감일]
  sheets.js에 due: '2026-10-10' 을 넣으면 학생 목록에 '3일 남음', '내일까지', '오늘까지', '기한 지남'이 보입니다.
  보낸 학습지는 날짜만 보입니다.

[필기 백업]
  필기는 그 기기에만 저장됩니다. 첫 화면 [필기 백업] → [백업 파일 만들기]로 파일 하나에 담아 두고,
  새 기기에서 [백업 불러오기]로 되살립니다. (아이패드는 '파일' 앱의 다운로드 폴더에 저장됩니다)
  내 PDF를 빼고 백업했다면, 새 기기에서 같은 PDF를 [PDF 열기]로 고르면 필기가 이어집니다.

[주의]
  - sheets 폴더에는 직접 만든 학습지만 올려 주세요. 저장소가 공개라 누구나 받을 수 있습니다.
    교재처럼 저작권이 있는 PDF는 올리지 말고, 각자 기기에서 [PDF 열기]로 여세요.
  - 필기는 그 기기에만 저장됩니다. 기기를 바꾸기 전에 [필기 백업]으로 백업 파일을 만들어 두세요.
